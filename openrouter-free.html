使用帮助

快速开始

  • 前往 openrouter.ai/keys 注册并创建 API Key（免费）
  • 将 Key 粘贴到输入框，点击「加载模型」
  • 加载成功后即可在输入框发送消息

模型选择

  • 自动（按性能）：系统根据近1小时滑动窗口统计，优先选择响应最快、成功率最高、速率压力最小的模型，失败后自动切换到下一个
  • 手动指定：从下拉列表选择特定模型，仅使用该模型（不自动切换）

超时设置

  • 模型(s)：单次模型请求的超时。超时后该模型进入冷却，自动切换到下一个模型重试。免费模型响应较慢，建议设置 15~30s。
  • 总计(s)：开始出字前的最长等待时间（含连接与切换模型）。一旦模型开始流式输出，总超时即停止生效，之后由「模型(s)」静默超时接管，因此正在持续输出的长回答不会被它中断。若超时前一个字都没收到，则提示「请求超时」。建议设置为模型超时的 3~5 倍。

键盘快捷键

  • Enter — 发送消息
  • Shift + Enter — 换行

📊 统计面板说明

  • 请求数：近1小时内该模型被调用次数
  • 平均响应：近1小时成功请求的加权平均耗时（近期数据权重更高，15分钟半衰期）
  • 成功率：时间衰减加权的成功比例（绿>80%，橙>50%，红≤50%）
  • 速率/min：近1分钟请求数 / 预估上限，接近上限时降低该模型优先级
  • 综合评分：成功率 × 速度加成 × 速率余量 × Provider惩罚 + UCB探索奖励
  • 冷却中：失败后按错误严重程度分级冷却（超时30s → 常规60s → 限速120s → 不可用180s），倒计时结束后恢复

常见问题

  • 加载模型失败：检查 API Key 是否正确，或网络是否能访问 openrouter.ai
  • 所有模型都失败：免费模型有并发限制，稍等片刻后重试，或增大超时时间
  • 响应很慢：免费模型共享算力，高峰期延迟较高，可在统计面板查看当前最快的模型并手动选择

📦 openrouter-client.js 使用方法

在页面引入脚本后即可直接使用 OpenRouterClient 类，无需安装任何依赖。支持 CJS require() 导入，TypeScript 类型定义见 openrouter-client.d.ts。

// 浏览器
<script src="openrouter-client.js"></script>
// Node.js / CJS
const OpenRouterClient = require('./openrouter-client');
// ESM (side-effect import)
import './openrouter-client.js';
const { OpenRouterClient } = globalThis;

构造函数

const client = new OpenRouterClient({
  timeoutMs:     20000,   // 单次模型请求超时(ms)，默认 20000
  maxRetries:    10,      // 最多切换模型次数，默认 10
  persistKey:    'or_perf', // localStorage 持久化 key（null=不持久化）
  debug:         false,   // 开启 console.debug 诊断输出
  onModelSwitch: (attempt, max, failedModelId, reason) => {
    console.log(`[${attempt}/${max}] 切换，原因: ${reason}`);
  },
});

事件系统 — 可观测性钩子

client.on('request:start',   ({ modelId, attempt }) => { ... });
client.on('request:success', ({ modelId, elapsedMs }) => { ... });
client.on('request:error',   ({ modelId, error, willRetry }) => { ... });
client.on('model:blacklist', ({ modelId, reason, duration }) => { ... });
client.on('model:release',   ({ modelId }) => { ... });
client.off('request:error', fn); // 取消订阅

loadModels(apiKey, options?) — 加载免费模型列表（自动重试）

const models = await client.loadModels('sk-or-v1-...', {
  retries:   3,    // 最多重试次数，默认 3
  backoffMs: 1000, // 初始退避(ms)，每次翻倍，默认 1000
});
// 返回: Array<{ id: string, ... }>  按 id 字母排序

// 用已存储的 key 重新加载：
await client.refreshModels();

send(messages, options) — 非流式请求

const { content, modelId, elapsedMs, totalElapsedMs } = await client.send(
  [{ role: 'user', content: '你好' }],
  {
    preferredModelId: null,    // null=自动选模型
    signal: controller.signal, // 可选，AbortSignal 用于取消
    temperature: 0.7,          // 可选，透传任何 OpenRouter API 参数
    max_tokens: 1024,
  }
);
// elapsedMs: 成功模型的耗时  totalElapsedMs: 含重试的总耗时

sendStream(messages, options) — 流式请求（AsyncGenerator）

for await (const chunk of client.sendStream(messages, { signal })) {
  if (chunk.done) {
    // 流结束: { done, content, modelId, elapsedMs }
    console.log(chunk.content);
  } else {
    // 增量内容: { delta, modelId }
    process.stdout.write(chunk.delta);
  }
}
// 失败自动切换模型重试，外部 abort 立即终止（不产生僵尸请求）

AbortSignal 取消 & 总超时

const ctrl = new AbortController();
setTimeout(() => ctrl.abort(), 60_000); // 60s 总超时

try {
  const result = await client.send(messages, { signal: ctrl.signal });
} catch (e) {
  if (e.name === 'AbortError') { /* 被取消或总超时 */ }
  if (e.code)  { /* e.code = ErrorCodes.EMPTY_RESPONSE 等 */ }
}
// 取消后内部请求也会被 abort，不会产生僵尸请求

统计 & 重置

const stats   = client.getAllModelStats();
// [{ modelId, score, stats: { avgMs, successRate, count, recentMin } | null,
//    blacklistedUntil, blacklistReason }]

const pvStats = client.getAllProviderStats();
// [{ provider, models, totalModels, availableModels, totalRequests,
//    successRate, weightedAvgMs, isRateLimited, ... }]

client.resetModel('meta-llama/...'); // 重置单个模型统计+解除黑名单
client.clearStats();                 // 清空所有统计和黑名单

可读写属性 & 生命周期

client.timeoutMs = 30000;        // 动态调整单次模型请求超时
client.freeModels;                // 只读，当前已加载的模型列表副本
client.destroy();                 // 释放定时器，标记为已销毁

ErrorCodes — 结构化错误码

OpenRouterClient.ErrorCodes.DESTROYED          // 客户端已销毁
OpenRouterClient.ErrorCodes.EMPTY_RESPONSE      // 空响应
OpenRouterClient.ErrorCodes.NO_AVAILABLE_MODEL  // 无可用模型
OpenRouterClient.ErrorCodes.ALL_MODELS_FAILED   // 所有模型失败
